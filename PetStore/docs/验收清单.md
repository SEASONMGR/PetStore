## 一、启动程序

### 1.1 命令行启动（推荐）

```powershell
cd F:\模拟工作区\ai-crew\项目\JavaWeb\t1\PetStore
.\mvnw.cmd -B -o spring-boot:run
```

- 看到 `Started PetStoreApplication` 即启动成功，默认端口 **8080**。
- 停止：在该窗口按 `Ctrl + C`。
- 若 `-o`（离线）因缺依赖失败，去掉 `-o` 联网重试一次。

### 1.2 在 IntelliJ IDEA 中运行

1. IDEA 打开目录 `F:\模拟工作区\ai-crew\项目\JavaWeb\t1\PetStore`（**注意不是 `t1` 根目录**）。
2. 右下角若提示 Maven 项目未加载，点 **Import Maven Project / Load Maven Project**（仓库不携带 `.idea/`，必须手动导入一次）。
3. 打开 `src/main/java/org/example/petstore/PetStoreApplication.java`，点 `main` 方法左侧绿色三角运行。
4. 控制台出现 `Started PetStoreApplication` 后，浏览器访问下表 URL。

### 1.3 注意事项

- 数据库是**内存库**，每次重启数据回到初始状态（2 个账号、3 分类、12 商品、22 SKU、2 订单）。这是预期的。
- 若 8080 被占用，可加参数改端口：`.\mvnw.cmd -B -o spring-boot:run -Dspring-boot.run.arguments=--server.port=8081`。

## 五、图片：属预期，不算缺陷

- `data.sql` 引用 **34 个** `/images/products/*.png`，`static/images/products/` 目录**当前为空**。
- 页面由 `petstore.js` 兜底：图片位显示**灰底**（`.is-missing` 样式），不会出现裂图标。
- **你验收程序通过后**，把图片按文件名放进 `src/main/resources/static/images/products/` 即可生效，**无需改代码**（数据库存的是完整路径 `/images/products/<文件名>.png`）。
- 需要的 34 个文件名清单：见 `需求规格说明.md` 附录，或直接看 `data.sql` 中的 `image_path` 列。
