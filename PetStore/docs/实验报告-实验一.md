#### 3.2.2 分层与包结构

`[待补]` 参考 `docs/架构说明.md` §2.1（`org.example.petstore` 下的 `controller` / `service` / `mapper` / `entity`）。

#### 3.2.3 关键设计决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 数据库 | H2 内存库（MySQL 模式） | 离线可跑、免安装；实验环境无 MySQL |
| ORM | MyBatis Plus（非原生 MyBatis） | 课程要求；`BaseMapper` 免除基础 CRUD 的 SQL 编写 |
| 视图 | 服务端渲染 Thymeleaf（非前后端分离） | 课程技术栈；避免引入 npm/CDN，保证离线可跑 |
| 主键策略 | 数据库自增 IDENTITY + `IdType.AUTO` | 与 H2 兼容，`GENERATED BY DEFAULT` 允许 `data.sql` 显式赋值 |
| 金额类型 | `DECIMAL(10,2)`，Java 侧 `BigDecimal` | 避免浮点误差 |
| 订单单价 | `lineitem.unit_price` 存成交快照 | 商品改价不影响历史订单 |
| 下架可见性 | 用户端分类页只查 `status='ON_SALE'` | 后台上下架与用户端显示形成隐式契约 |

**依据**：`schema.sql:1-9` 建模约定注释、`CatalogService.java:23,50-56`、`架构说明.md`。
