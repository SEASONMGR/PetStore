### 2.3 用户模块分层（本轮新增）

```
浏览器
  │  GET  /account/login        → AccountController.loginPage()      :38-45
  │  POST /account/login        → AccountController.login()          :51-72
  │  GET  /account/register     → AccountController.registerPage()   :75-80
  │  POST /account/register     → AccountController.register()       :85-137
  │  GET  /account/logout       → AccountController.logout()         :140-145
  ▼
AccountService
  ├─ login(username, password)      :41-57   ← 明文 equals + status=='ACTIVE' 校验
  ├─ register(account)              :69-107  ← 用户名/邮箱查重；强制 admin=FALSE、status=ACTIVE
  └─ findByUsername(username)       :110-116
  ▼
AccountMapper（extends BaseMapper<Account>）→ H2: account
```

**登录链路要点**（`AccountController.java`）：

1. `POST /account/login` 收 `username`、`password` 两个 `@RequestParam`（`required = false`）；
2. 空值 → 回 `account/login` 视图并带 `error`、`username`（`:56-60`）；
3. `accountService.login(...)` 返回 `Optional<Account>`；空 → 同一句"用户名或密码错误"（`:62-66`，**不区分账号是否存在**，避免枚举账号）；
4. 成功 → **写入 session 前把 `password` 置 `null`**（`:67-70`），`session.setAttribute("loginUser", account)`（键名常量 `SESSION_LOGIN_USER`，`:29`）；
5. `redirect:/catalog`（`:71`）。

**注册链路要点**：

1. 11 个 `@RequestParam`（3 必填 + 8 选填，`required = false`），**驼峰命名**（`firstName` 等，与列名 `first_name` 不同）；
2. 必填校验（`username`/`password`/`email`，`:110-114`）；
3. `accountService.register(...)` 抛 `IllegalArgumentException`（用户名/邮箱重复）→ 回注册页带 `error` 与**回填对象**（`:130-134`）；
4. **防越权**：`AccountService.register` 不采信前端传的 `admin`/`status`，强制 `admin=FALSE`、`status=ACTIVE`（`:100-102`）；
5. 成功 → `redirect:/account/login?registered=true`（`:136`），登录页用 `${param.registered}` 显示成功提示。

**退出**：`session.removeAttribute("loginUser")` + `session.invalidate()`，再 `redirect:/catalog`（`:140-145`）。

本项目从 v1.1 起要求**技术接口落成文件**：`项目/docs/接口契约.md`（dev-01 维护，v1.1，226 行）。

**契约中已固化的三个易错点**（对写页面/写后台都有用）：

1. **业务码不可拼 URL**：`Category.catid`（`"DOGS"`）、`Product.productid`（`"DOG-001"`）、`Item.itemid` 均为 String 业务码；路径变量收 `Integer`，用业务码会 400（`MethodArgumentTypeMismatchException`）。站内链接一律用 `id`。契约 §2.1。
2. **`imagePath` 是完整路径**：存 `/images/products/dog-golden.png`（含前缀），Thymeleaf 用 `th:src="@{${p.imagePath}}"`，**不得再拼前缀**，否则变成 `/images/products//images/products/xxx.png`。契约 §四。已核查 `category.html:33`、`product.html:34` 用法正确。
3. **`error/404` 有两个来源**：业务走查（`ProductController.notFound`）与框架级 `BasicErrorController`，属性不同，模板须对 `path` 等做空值兜底。`error/404.html` 已用 `${status} ?: 404`、`${path} ?: '（未知）'` 兜底（`:14,22,26`）。

## 四、实体与表映射对照

| 实体 | `@TableName` | 主键 | 备注（**易错点**） |
|---|---|---|---|
| `Account` | `account` | `id` AUTO | `admin`: `Boolean`；`status`: `ACTIVE`/`DISABLED` |
| `Category` | `category` | `id` AUTO | 业务码属性名 **`catid`**（全小写，String，不可拼 URL） |
| `Product` | `product` | `id` AUTO | 业务码属性名 **`productid`**；外键 `categoryId` |
| `Item` | `item` | `id` AUTO | 业务码属性名 **`itemid`**；外键 `productId` |
| `OrderStatus` | `order_status` | `id` AUTO | `code` = P/C/D/X |
| `Orders` | `orders` | `id` AUTO | 业务码 **`orderid`**（Integer）；外键 `accountId`、`statusId` |
| `LineItem` | `lineitem` | `id` AUTO | `unitPrice` 为成交单价快照 |

> **列名映射规则**：`map-underscore-to-camel-case` 只处理带下划线的列。`productid`、`catid`、`itemid`、`orderid` 无下划线 → 属性名保持全小写；`category_id`、`product_id`、`first_name` → `categoryId`、`productId`、`firstName`。
> 完整类型表见 `项目/docs/接口契约.md` §三（**以其为准**，本文不重复维护）。

## 六、数据初始化机制

```
SpringApplication.run
  ↓ HikariCP → jdbc:h2:mem:petstore
  ↓ spring.sql.init.mode = always
  ↓ schema.sql（先按依赖倒序 DROP 再 CREATE）
  ↓ data.sql（插入演示数据）
  ↓ MyBatis Plus 初始化 + Mapper 扫描
  ↓ 内嵌 Tomcat :8080
```

**幂等性**：`schema.sql:11-17` 先 `DROP TABLE IF EXISTS`（lineitem → orders → order_status → item → product → category → account）再建。内存库存于 JVM 期间（`DB_CLOSE_DELAY=-1`），**进程重启即全部重置**。

**初始数据规模**（`data.sql` 实测）：

| 表 | 行数 | 内容 |
|---|---|---|
